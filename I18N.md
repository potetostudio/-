Poteto STUDIO supports Japanese and English UI. Japanese is the default;
`pt_language` in localStorage retains the user's explicit selection. Language
pickers are available before login, in the navigation bar, and in Settings.

`i18n.js` contains the English catalog, using Japanese source strings as keys.
For static UI text use `<span data-i18n="日本語">日本語</span>`. For tooltips,
placeholders, or accessible labels, use `data-i18n-title`,
`data-i18n-placeholder`, or `data-i18n-aria-label`. Marked UI fragments added
dynamically are translated automatically. Never mark user-supplied content.

Use `t('日本語')` for UI strings created in JavaScript. Use
`setUiText(element, function () { return t('日本語'); })` for a transient label
that must update during a language switch. A normal textContent assignment
replaces that binding when it changes the displayed text.

AI instructions, user messages, app titles, source code, and iframe content
are not translated. Changing the UI language does not change AI output language.
No external translation API or build step is required.

Run browser regressions from the repository root:

    PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v

The tests use the installed Python Playwright package and `/usr/bin/chromium`
(or `CHROMIUM_PATH`). Firebase is replaced by an in-memory test double; these
checks do not verify production Firebase rules or network availability.
